# Credential inventory — React2Shell compromise of `i-0b7f49ca3e9852d4b`

Rule applied throughout: **anything that was readable by `ec2-user` on the compromised host,
or present in any process environment on it, is exposed.** The attacker ran as `ec2-user`
(RCE inside `next-server`), `ec2-user` has passwordless sudo, and the attacker's own tooling
(`nextjs_crack.py`) is documented to harvest environment variables and `.env*` files and post
them to its hub. Evidence for the "exposed" verdicts is in `01-investigation-report.md`.

No secret **values** appear in this file. Legend: **R** = rotate (issue a new value, revoke
the old at the provider), **D** = delete/revoke, **N** = new value already generated by
`deploy/v2/aws/provision-secrets.sh`.
